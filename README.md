# Binance Motion Pack

Готовые анимации выложены отдельными файлами в папке [`video/`](video/). Там находятся 8 сцен, 6 переходов, заставки, версии без звука, монтажные маски, прозрачные слои и общий ролик для просмотра. Основные ролики — MP4, 1920×1080, 30 FPS.

Откройте [папку с видео](https://github.com/murdegun/Video-gener/tree/main/video), выберите нужный файл и нажмите **Download**. Большие видео хранятся через Git LFS. Чтобы скачать всю папку сразу:

```sh
git lfs install
git clone https://github.com/murdegun/Video-gener.git
cd Video-gener
git lfs pull
```
