# Binance Motion Pack

Архив содержит полный пакет кинематографических анимированных вставок для документального видео о кибератаке на Binance. В нём есть 8 основных сцен, 6 переходов, заставки, звуковые эффекты, исходные проекты Blender и Python-скрипты, предпросмотр и финальные видео.

## Скачать

Архив хранится через Git LFS. Установите Git LFS и выполните:

```sh
git lfs install
git clone https://github.com/murdegun/Video-gener.git
cd Video-gener
git lfs pull
```

Или откройте `BINANCE_MOTION_PACK.zip` в списке файлов GitHub и нажмите **Download**.

Размер архива: 1,023,767,582 байта (около 977 MiB).
